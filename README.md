# Assignment-2-Power-BI--DAX-Data-Visualization
This project focuses on analyzing sales performances using Power BI. The objective is to transform sales data through data modeling, DAX calculations and interactive visualizations.
What I did,
1. Calculated Columns        
Created the following calculated columns in the Order Details table,     
-Category Type: Combined Category and Sub-Category using the CONCATENATE function.    
-Revenue per Order: Calculated by multiplying Amount and Quantity.     
-Sales Category: Categorized sales as Above Average or Below Average based on the Amount value using the IF function.     
-Profit Margin: Calculated by dividing Profit by Amount.

2. Calculated Measures              
-Created the DAX measures for Order Count, Average Profit in Delhi and YTD Sales.
3. Data Visualization                                       
-Created Clustered Column Chart for Sales Target Achievement by Category.                                   
-Created Donut Chart for Maximum Profit Margin by Sub-Category.                                
-Created Monthly Sales Trend using Line Chart.                                           
-Created Scatter Chart for Comparison of Profit and Quantity by Sub-Category.                                     
-Comparison of Total Sales Amount and Target using Cards and Multi-row Card.                                                   
-Created Sales Performance Matrix for compare actual sales and targets across categories and months.                                                
-Created Geographic Sales Analysis to visualize total sales by city using Map.                     
-Created Sales Distribution by Sub-Category using Tree map.                     
-Created Order Count Analysis by State using Funnel Chart.
